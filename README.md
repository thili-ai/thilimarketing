# thilimarketing

The practice files and templates for **AI for Marketing** — a short course on using an AI assistant to group
loyalty customers, measure a campaign, build a churn watch-list and read customer reviews for a food company,
and on checking what it gives you.

There is no code here. It is a set of spreadsheets to practise on and some blank templates.

> ⚠️ **A practice company, not a real business.** *Nila Foods* is invented: a fictional Kerala packaged-foods
> company, fictional outlets and members, fictional reviews. The data is deliberately imperfect, the way real
> exports are. **Do not clean it before you use it.** There are no answers in this folder.

## What is here

| File | Used in | What it is |
|---|---|---|
| `customers.csv` | Lessons 1, 3 | 3,000 loyalty members: join date and channel, home outlet, region, message opt-in, delivery complaints to March 2025, and two fields used in lesson 3 |
| `purchases.csv` | Lessons 1, 3 | About 26,500 purchases from January 2024 to 12 October 2025 |
| `outlets.csv` | Lesson 2 | The 40 outlets, and which ran the Onam campaign |
| `outlet_sales_weekly.csv` | Lesson 2 | Weekly sales for each outlet |
| `events_calendar.csv` | Lesson 2 | Festival dates and the Onam Sadya Offer |
| `reviews.csv` | Lesson 4 | 300 customer reviews, in English |
| `fifty-reviews-to-label.csv` | Lesson 4 | The fifty reviews to label yourself, with a blank column for your label |
| `decision-memo-template.md` | Lesson 5 | A one-page layout for the memo |
| `claim-ledger.md` | Lesson 5 | A blank table for every figure and where it came from |
| `prompts.md` | All | Where the prompts are collected |

There is no age, gender, income, job or device for any member, by design.

## Where this comes from

**AI for Marketing** is the marketing lab of *AI for Functions*, a programme for management students and working
managers, on [Learn Fast](https://ask.thili.ai).
